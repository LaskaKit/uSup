# LaskaKit μŠup for DIP adapter

Add μŠup to a sensor, display or anything else with I2C. The adapter converts μŠup to a 2.54 mm pin header that you solder to a module without a μŠup connector – an OLED display, for example. The header pin order is set by solder jumpers on the back of the board, so the adapter also fits modules with a non-standard pinout. The second μŠup connector lets you daisy-chain more devices on the bus.

![Solder jumpers on the back](img/2.jpg)

## Specifications

- **Connectors:** 2× μŠup (JST-SH 4-pin, 1 mm pitch, locking), wired in parallel
- **Pin header:** 4 pins, 2.54 mm pitch (labelled SDA, SCL, GND, VCC)
- **Pinout configuration:** solder jumpers on the back – any μŠup signal can be routed to any header pin
- **μŠup pinout:** 1 – GND, 2 – VCC (3.3 V), 3 – SDA, 4 – SCL
- **Compatibility:** μŠup, SparkFun Qwiic, Adafruit STEMMA QT
- **PCB size:** 14.0 × 12.4 × 1.6 mm

The display and pin header are not included.
